# novel-auto-reader

浏览器扩展：章节页自动预取后续章节并拼接成一条长页，滚动连读；读过去的旧章节自动清理，弱网会重试并断点续抓。

面向结构类似「全本同人小说」的站点（`.read_chapterName` / `.read_chapterDetail` / `.pageNav`），其他站点可在设置页添加域名。

## 功能

- 打开任意章节页后用 / 打开扩展，读到当前章末尾直接继续下一章，不用点「下一章」
- 一次抓一批（章数可调），已备未读剩到设定数量时才抓下一批
- 当前章上方只保留可调数量的旧章节，更早的删除并精确补偿滚动位置
- 断网/失败时从第一个没抓到的章继续，不重复抓；缓存到 localStorage，刷新页面不重抓
- 目录地址随阅读位置更新（`history.replaceState`），标题同步成当前章
- 右下角磁吸面板：悬停显示进度、暂停、重试、设置
- 设置页：一次抓取章节数、剩余多少章开抓、上方保留章节数、额外站点

## 安装

1. 打开 `edge://extensions`（或 `chrome://extensions`）
2. 打开「开发人员模式」，选「加载解压缩的扩展」，选中本目录
3. 打开章节页即可；首次使用后可在扩展详情里进入「设置」

## 文件

- `content.js` — 正文抓取、拼接、滚动清理、面板
- `manifest.json` — MV3 配置，内置 qbtr.org / qbtr.cc / bqquge.org
- `background.js` — 把设置页添加的额外站点注册为动态 content script
- `options.html/css/js` — 设置页

## 说明

- 章节正文只在本机浏览器内抓取和缓存，扩展不上传、不分发任何正文内容；正文版权归原作者与站点所有
- 站点可能有反爬/访问条款，请仅作个人阅读使用，不要高频批量抓取
- 站点改版后选择器可能需要调整
